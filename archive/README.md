# Archived Coach Strategy Docs

The rebuilt coach uses `COACH_OPERATING_SYSTEM.md` plus Supabase `coach_state` as the active source of truth.

The older numbered markdown files remain in the repository as reference material for now because scripts, logs, and historical notes still link to them. They are no longer required reading for workout generation.

If a durable rule is rediscovered in an archived file, move the rule into `COACH_OPERATING_SYSTEM.md` or `coach_state` instead of adding another active planning file.
