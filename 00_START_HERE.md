# 00_START_HERE — Single Entry Point

If you are rebuilding or running Todd's coach, start here.

## Canonical files (minimal set)
1. `31_COACH_OPERATING_SYSTEM.md` ← **primary source of truth** for coaching logic, rules, weekly design, and workflow.
2. `24_MASTER_COACH_PROMPT.md` ← voice + response behavior constraints.
3. `HEALTH_DATABASE.json` ← historical/readiness/training/nutrition records.
4. `DAILY_LOG.md` + `NUTRITION_LOG.md` ← daily summaries and closeout context.
5. `IPHONE_SHORTCUT_SETUP.md` + `MOBILE_CODEX_COACH_SETUP.md` ← mobile interaction + automations.

## Direction
- Prefer **one-file planning and decision rules** in `31_COACH_OPERATING_SYSTEM.md`.
- Treat older planning docs as archival unless explicitly referenced.
- Keep outputs decisive, brief, and actionable.
